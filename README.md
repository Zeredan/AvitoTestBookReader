# Приложение для чтения книг

## Функциональность

-   Автологин при запуске приложения через FirebaseAuth.
-   Просмотр и редактирование профиля: изменение фото и никнейма с
    загрузкой изображения в Yandex Object Storage и автоматическим
    обновлением глобальной ссылки.
-   Возможность выхода из аккаунта.
-   Загрузка книги в облако Yandex Cloud Storage с локальным сохранением
    файла и добавлением записи в Room.
-   Скачивание книги из облака, если локальный файл отсутствует.
-   Удаление книги как локально, так и в облаке --- с реактивным
    обновлением списка.
-   Поддержка прогресса чтения книги, обновляемого по мере чтения
    (чанками).
-   Экран чтения книги с возможностью изменения темы, размера шрифта и
    интервала между строками.
-   Поддерживается формат .txt.
-   Отображение прогресса загрузки книги.
-   Поиск книг по названию и автору.
-   Реализован сплэш-экран и поддержка edge-to-edge.
-   Механизм смены темы приложения, реализованный через core:ui
    синглтон.
-   Gradle flavors (mock/real) с переключением через Build Variants.
-   YAML файл для CI сборки.

## Использованные технологии и архитектура

### Архитектура

-   Чистая архитектура (Clean Architecture).
-   Многомодульность: `app`, `feature`, `domain`, `data`, `core`.
-   MVVM.
-   Dependency Inversion.
-   Реактивность через Kotlin Flow.
-   Jetpack Compose для UI.

### Интеграции и инструменты

-   Firebase Authentication --- авторизация, автологин.
-   Firestore --- хранение метаданных книг и профиля.
-   Yandex Cloud Object Storage --- хранение файлов книг и аватарок
    пользователей.
-   Room --- локальное хранение скачанных файлов и данных.
-   Coroutines --- асинхронность.
-   Navigation Component + BottomNavigation.
-   Hilt - Dependency Injection
-   DataStore - хранение настроек
